## 合成样例说明

使用“白底两个红圆、不添加文字”的虚构任务，演示三次模拟尝试：理解错误、提示词遗漏、请求明确但输出不满足。所有 SVG 由确定性文本编写，均不是模型生成，没有付费调用或真实模型性能结论。

三份请求快照保留完整模拟提示词；一个独立 fixture 文件保存当时理解、输入顺序、期望观察与模拟输出。第三次改为模拟 API 图生图，验证报告能够叙述跨路径关系。规范中的未知字段用 null＋缺失原因表示。
