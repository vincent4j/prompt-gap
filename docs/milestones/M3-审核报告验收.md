## 这一轮完成了什么

- **三层审核**：分别记录需求理解、提示词覆盖、输出符合程度；允许多处同时偏差，也允许无法判断。检查项必须追溯用户原话，不能只从提示词提取。
- **证据门槛**：引文必须匹配原记录；缺当时理解不能判断理解正确与否；缺图不能给确定视觉结论；图生图必须检查目标修改和保留项。
- **报告生成**：当前 Agent 按需比较事实和看图，程序校验关联并生成主报告、时间线详情及底层诊断文件。程序本身不识图，也不证明 Agent 的判断正确。
- **纠错版本**：用户反馈追加保存，重审生成新版本，旧报告不覆盖。准备后事实改变会阻止保存过期审核。
- **能力研究**：提供用户主动选择入口、研究方法及按模型/版本/任务查询的证据缓存；不默认联网，不把执行失败写成“模型没有能力”。

## 开销和限制

日常留档不触发审核。用户主动查看时才准备所选记录（默认最近三次）、读取必要图片、生成报告，不额外调用评审模型。审核仍会消耗当前 Agent 的 Token，真实端到端时间和 Token 未测，不能称为零开销。

为保留旧报告可读性，每份审核会保存所选图片的原字节副本；这是按需报告时的磁盘开销，不是每次生图的开销。缺证据时保守标 unknown；字段校验不能代替人对语义和视觉结论的 review。
