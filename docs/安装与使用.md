# PromptGap 安装与使用

## 日常使用

在 Codex 输入框输入 `/p`，从客户端已有的 Skill 候选列表选择 **PromptGap**，发送后按数字菜单操作。无需记住命令、目录或任务编号；这不是另外开发的斜杠命令系统。

个人 Skill 只安装一次，各项目分别启用。首次选择启用时，Agent 会说明并维护该项目的 AGENTS.md、.gitignore 和本地留档配置。已经启用的项目不重复询问安装；有记录时可看最近报告、选择历史任务或关闭。关闭不删除历史，之后可以恢复。

历史任务列表包含标题、时间、调用次数及反馈摘要，按编号选择；超过一页可以翻页。选中的编号绑定当时的任务，不会因为新任务插入而串号。

普通生图只留事实；主动查看报告时才分析。成功生成也能查看完整过程。能力研究需另外选择，不自动联网、换模型或生图。

## 安装与分享

安装 Node.js/npm 后，在终端运行，也可以交给 Agent 执行：

```bash
npx skills add vincent4j/prompt-gap
```

按提示选择 Codex 和安装范围。也可明确指定 Codex 的个人安装：

```bash
npx skills add vincent4j/prompt-gap --agent codex --global
```

只想查看可安装 Skill、不执行安装：

```bash
npx skills add vincent4j/prompt-gap --list
```

参数依据 [skills 官方说明](https://github.com/vercel-labs/skills#install-a-skill)。分享时直接发送仓库链接和安装命令，不提供独立安装包。已有同名安装时先检查差异再确认更新；安装成功不等于项目留档已开启，也不等于客户端候选发现已验证。

运行需要 Python 3.10+；Pillow 可选。PyYAML 只用于开发格式检查，不是运行依赖。记录器不上传数据，但原生生图工具/API 自身的数据处理规则不受它控制。

## 已知边界

留档依赖 Agent 在工具调用前后执行协议，并非后台拦截。更换工具时核对实际可见字段和覆盖范围；完全未留档的调用无法自动找回。内置工具隐藏的版本、费用和内部提示词不能猜补。真实异步生产接口及总体 Token 开销仍未完整验证。

停止某项目留档请在菜单选择关闭。卸载 Skill 应先关闭仍启用的项目，再移除个人 Skill 文件夹；历史数据由用户决定是否保留，不自动删除。
