# PromptGap

Trace the gap from user intent to model output.

定位从用户意图到模型结果之间，偏差最早发生在哪里。

## 项目定位

PromptGap 计划成为一个独立、可移植、可分享的提示词审核 Skill。它记录用户原始需求、AI 对需求的理解、实际发送的提示词与参考输入、模型返回结果。用户可以了解一次成功生成的完整过程，也可以分析结果与预期不一致的原因；不需要先出错或反复尝试才能查看报告。

它解释的是可观察的执行过程，不宣称揭示模型内部推理或生成机制。

审核按时间顺序关注三个维度：

1. **需求理解偏差**：AI 是否正确理解用户想完成的事情？是否遗漏需求，或引入未经确认的假设？
2. **提示词覆盖偏差**：实际提示词、参考图片与参数是否完整、准确地表达了需求？
3. **模型执行偏差**：需求与提示词正确时，生成模型是否按要求执行？

一项问题可以涉及多个维度。证据不足时应标记无法确定，不将推测写成已证实的根因。

## 首期范围

- 文生图与图生图的需求、提示词、输入素材和输出追踪。
- 调用前保存需求理解和实际请求快照。
- 项目启用后轻量留档；用户从菜单主动复盘时提供完整审核报告，逐项比较预期与实际结果。
- 记录审核方法、结论、风险、证据和下一步建议。
- 保持项目与模型无关；业务专用规则由使用方补充。
- 同时支持内置工具和 API 的记录设计；API 请求保留原结构，不维护固定供应商适配名单。

视频和文字生成审核作为后续扩展方向，尚未实现。
